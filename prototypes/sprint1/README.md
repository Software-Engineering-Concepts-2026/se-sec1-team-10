# Sprint 1 Prototype: Food Logging

## 1. Feature Name & Referenced User Story
- **Feature Name:** Food Logging
- **User Story:** ในฐานะวัยทำงาน ฉันต้องการบันทึกข้อมูลอาหารที่รับประทานในแต่ละมื้อ เพื่อให้สามารถติดตามพฤติกรรมการกินได้

## 2. Tracer Bullet vs Prototype
- **Type:** Prototype
- **Rationale:** ชิ้นงานนี้เลือกใช้แนวทาง **Prototype** เพราะสร้างขึ้นเพื่อสำรวจหน้าตา UI และ Flow การกรอกบันทึกข้อมูล (Food Logging) บนฝั่ง Client-side เท่านั้น โดยไม่ได้ต่อเชื่อมฐานข้อมูลหรือ API จริงแบบ End-to-End ซึ่งโค้ดส่วนนี้จะถูกทิ้ง/เขียนใหม่เมื่อพัฒนาจริงในระบบหลัก (ต่างจาก Tracer Bullet ที่เน้นวางโครงสร้างระบบจริงทุกชั้นตั้งแต่แรก)

## 3. สิ่งที่ทำได้ (Capabilities)
- บันทึกชื่ออาหาร, เลือกมื้ออาหาร, และพรีวิวรูปภาพอาหาร
- กรอกสารอาหาร (คาร์บ, น้ำตาล, โปรตีน, ไขมัน) และคำนวณพลังงานรวม (kcal) แบบ Real-time
- เพิ่ม/ลบ รายการวัตถุดิบและส่วนประกอบแบบ Dynamic
- ปลดล็อกปุ่มบันทึกเมื่อกรอกข้อมูลจำเป็นครบถ้วน

## 4. สิ่งที่ไม่ได้ทำ (Deliberately Out of Scope)
- ระบบล็อกอินและ Authentication
- การบันทึกข้อมูลลงฐานข้อมูลจริงแบบถาวร (รีเซ็ตเมื่อรีเฟรชหน้าเว็บ)
- การเชื่อมต่อ AI วิเคราะห์รูปภาพอัตโนมัติ

## 5. Next Step (Sprint 2)
- นำ UI และ Flow ของ Food Logging ไปพัฒนาเป็น Tracer Bullet โดยเชื่อมต่อกับ Backend API และ Database จริง
