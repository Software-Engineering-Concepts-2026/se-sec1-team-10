# final-reflection-67021130

**1. What did you build:** พัฒนาส่วนกิจกรรมและการติดตามสุขภาพของ LifeBalance เช่น หน้า Exercise, Today, กราฟสุขภาพ และหน้าสรุปรายสัปดาห์ เพื่อให้ผู้ใช้ดูข้อมูลกิจกรรมและติดตามความคืบหน้าของตัวเองได้

**2. What problem did you solve:** ตรวจสอบความถูกต้องของข้อมูลกิจกรรมและยอดพลังงาน โดยเฉพาะเมื่อผู้ใช้เพิ่ม แก้ไข หรือลบกิจกรรม ข้อมูลที่แสดงในหน้า Today และกราฟควรอัปเดตให้ตรงกัน เพื่อให้ผู้ใช้เห็นข้อมูลที่ถูกต้อง

**3. What technical decision are you proudest of:** ผมให้ความสำคัญกับการตรวจสอบข้อมูลให้ตรงกันระหว่างแต่ละหน้าของแอป เพราะถ้ายอดพลังงานหรือกราฟแสดงผลไม่ตรงกับข้อมูลจริง อาจทำให้ผู้ใช้เข้าใจผิดได้ จึงควรตรวจสอบทั้งการคำนวณและการแสดงผลควบคู่กัน

**4. What failure taught you the most:** ผมได้เรียนรู้ว่าการทำให้โปรแกรมแสดงผลได้ไม่ได้หมายความว่าผลลัพธ์จะถูกต้องเสมอไป จึงต้องทดสอบหลายกรณี เช่น การเพิ่ม แก้ไข และลบกิจกรรม รวมถึงวันที่ไม่มีข้อมูล เพื่อให้มั่นใจว่าระบบทำงานได้ถูกต้อง

**5. What would you do differently:** หากได้ทำใหม่ ผมจะเตรียมข้อมูลทดสอบและกำหนดผลลัพธ์ที่คาดหวังไว้ตั้งแต่แรก เพื่อให้ตรวจสอบความถูกต้องได้ง่ายขึ้น รวมถึงวางแผนแบ่งงานและสื่อสารกับเพื่อนในทีมให้ชัดเจนก่อนเริ่มพัฒนา

**6. How did you embody Tip 52 (Delight Users):** ผมคำนึงถึงการใช้งานของผู้ใช้ โดยพยายามให้ข้อมูลกิจกรรม ยอดพลังงาน และกราฟแสดงผลได้เข้าใจง่ายและถูกต้อง เพื่อช่วยให้ผู้ใช้ติดตามสุขภาพและความคืบหน้าของตัวเองได้สะดวกขึ้น

**7. How did you embody Tip 53 (Sign Your Work):** ผมรับผิดชอบงานในส่วนที่ได้รับมอบหมาย และให้ความสำคัญกับการตรวจสอบโค้ดก่อนส่งงาน รวมถึงใช้ Git บันทึกการเปลี่ยนแปลง เพื่อให้ทีมสามารถตรวจสอบและติดตามงานที่ทำได้

**8. What value did this experience add to your SE journey:** การทำโปรเจกต์ LifeBalance ช่วยให้ผมเข้าใจการพัฒนาซอฟต์แวร์มากขึ้น ทั้งการตรวจสอบข้อมูล การทดสอบระบบ และการทำงานร่วมกับทีม ทำให้เห็นว่าการพัฒนาแอปที่ดีไม่ใช่แค่ทำให้ใช้งานได้ แต่ต้องมีข้อมูลที่ถูกต้องและตอบโจทย์ผู้ใช้ด้วย
