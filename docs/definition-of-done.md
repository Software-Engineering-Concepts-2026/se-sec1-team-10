
# Definition of Done (DoD)


## เกณฑ์การทำ Issue ให้เสร็จ

1. **พัฒนางานตามรายละเอียดของ Issue ครบถ้วน**
   Feature หรือฟังก์ชันที่ระบุไว้ใน Issue ต้องถูกพัฒนาให้ครบตาม Acceptance Criteria

2. **ทดสอบการทำงานเรียบร้อย**
   ต้องทดสอบ Feature ทั้งกรณีปกติและกรณีที่ผู้ใช้งานกรอกข้อมูลผิดหรือใช้งานไม่ถูกต้อง และต้องไม่มี Error ที่กระทบต่อการใช้งานหลัก

3. **Code ถูกตรวจสอบและบันทึกลง Git**
   Code ต้องผ่านการตรวจสอบจากสมาชิกในทีม และ Commit ขึ้น Repository เรียบร้อย เพื่อให้สามารถติดตามการเปลี่ยนแปลงได้

4. **สามารถใช้งานได้จริง**
   Feature ต้องทำงานได้ตามที่ออกแบบไว้ และไม่ทำให้ Feature อื่นที่เกี่ยวข้องเกิดปัญหา

5. **ทีมตรวจสอบและยอมรับงาน**
   สมาชิกในทีมต้องตรวจสอบผลลัพธ์และเห็นว่างานตรงตาม Requirement ก่อนเปลี่ยนสถานะ Issue เป็น `Done`
