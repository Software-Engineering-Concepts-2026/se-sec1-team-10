## วิธีตรวจและขอบเขตหลักฐาน

- อ่าน component ปัจจุบันและ `docs/ui/lifebalance-ui-design-brief.md` โดยให้ข้อกำหนดล่าสุดมีลำดับเหนือข้อความเก่าใน brief
- Luna ตรวจ source; หัวหน้าตรวจภาพและหน้าจอจริงที่ `http://127.0.0.1:5173/`
- หน้าจอจริง: วันนี้, บันทึกหลัก, กรอกอาหาร, เพิ่มส่วนประกอบ, กิจกรรม, ความคืบหน้า, เปิดฟอร์มน้ำหนัก, บัญชี, ข้อมูลส่วนตัว, เป้าหมาย และเตือนมื้ออาหาร โดยไม่กดบันทึก/ลบ/เปิดสิทธิ์กล้องหรือแจ้งเตือน
- หน้าล็อกอิน/สมัครสมาชิก, กล้องไม่ได้รับสิทธิ์, ผลวิเคราะห์ภาพ, ค้นหา, ประวัติทั้งหมด, ประวัติรายวัน, แก้ไขอาหาร, BMI และสถานะเชื่อมต่อ/โหลดผิดพลาด ตรวจด้วย browser ทดสอบและ API จำลองทุก `/api/*` ไม่มีคำขอไป Supabase หรือบริการ AI จริง
- แคปหน้าหลักและฟอร์มชุดหลักที่ความกว้าง 320, 360, 390 พิกเซล (สูง 844); ตรวจ Today เพิ่มที่ 1440×1000 และกล้องที่ 320×667, 360×800, 390×844
- ไม่พบ horizontal overflow ในหน้าหรือขนาดที่เก็บหลักฐาน; ไม่พบ page error ในชุดแคปหลัก ผลนี้ไม่ใช่การยืนยันทุกหน้า desktop ทุกขนาด หรือการทดสอบคีย์บอร์ดมือถือจริง
- ประวัติรายวันใน fixture ใช้ข้อมูลตัวอย่างเพื่อดู layout ไม่ใช้ยืนยันความถูกต้องของการกรองข้อมูล backend

## สิ่งที่ดูเรียบร้อยแล้ว

| ส่วน | ผลตรวจ UI |
| --- | --- |
| เข้าสู่ระบบ / สมัครสมาชิก | โลโก้และทิศทางภาพสอดคล้องกัน มี label ช่องกรอกและทางสลับฟอร์ม |
| เริ่มระบบ | เมื่อเชื่อมต่อไม่ได้มีปุ่มลองอีกครั้ง ต่างจากจุด retry ที่ยังขาดด้านบน |
| Today | สรุปวงแหวนและสารอาหารอยู่ร่วมกัน สีคาร์บส้ม โปรตีนแดง ไขมันเหลือง; รายละเอียดเพิ่มเติมพับได้ |
| บันทึก / ค้นหา / ประวัติ | แยกถ่ายภาพ กรอกเอง และกิจกรรม; ค้นประวัติและ catalog; มีแก้ไข/ลบ/ใช้รายการซ้ำตามระบบเดิม ไม่มี QR scanner |
| กรอก / ตรวจอาหาร | ลำดับรูปและชื่อ → มื้อ/วันที่ → พลังงาน/สารอาหาร → ส่วนประกอบ → บันทึก; คำอธิบาย AI และแหล่งข้อมูลย้ายเข้า disclosure แล้ว |
| กิจกรรม | มีวันที่ ประเภท ระยะเวลา รายการกิจกรรม และสรุปพลังงานในทิศทางเดียวกับหน้าหลัก |
| ความคืบหน้า | มีสรุปน้ำหนัก 4 ค่า สลับน้ำหนัก/BMI ช่วงเวลา กราฟ ประวัติ และฟอร์มบันทึกน้ำหนักโดยตรง |
| สรุป 7 วัน | ระบุสีรับประทาน/เผาผลาญ และชี้แจงว่าไม่มีบันทึกไม่ได้หมายถึงกิน 0 kcal |
| บัญชี / ข้อมูลส่วนตัว | เอาการ์ดน้ำหนัก/ส่วนสูง/BMI ที่แสดงถาวรออกแล้ว ข้อมูลอยู่ใน “ดูข้อมูลโปรไฟล์”; มี 3 เมนูเดิมและออกจากระบบ ไม่มี settings cog |
| เป้าหมาย | มี TDEE แนวทางเป้าหมาย และค่าปัจจุบัน/หลังบันทึก; วิธีคำนวณพับได้ |
| เตือนมื้ออาหาร | แสดงสถานะสิทธิ์และข้อจำกัดว่าต้องเปิดแอปไว้ ไม่ทำให้เข้าใจว่าเป็นการแจ้งเตือนเบื้องหลังสมบูรณ์ |

## ข้อจำกัด

รอบนี้ไม่ทดสอบการบันทึกจริง การลบจริง ความเร็ว/ความแม่นยำของ AI กล้องมือถือจริง การแจ้งเตือนจริง และเว็บ production จึงไม่สรุปว่าส่วนเหล่านี้ผ่านจากภาพ UI เพียงอย่างเดียว ไม่รัน regression suite เดิมทั้งหมดซ้ำเพราะไม่มีการแก้โค้ด
