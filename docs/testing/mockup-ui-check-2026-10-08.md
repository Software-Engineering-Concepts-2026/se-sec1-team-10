## ขอบเขตที่ยืนยันจาก diff

- ไม่เพิ่ม route, ปุ่มความสามารถใหม่, QR/barcode scanner หรือหน้าตั้งค่ารวมศูนย์
- Account คงเมนูข้อมูลส่วนตัว เป้าหมาย แจ้งเตือนมื้ออาหาร และออกจากระบบ พร้อมการจัดการรูป/ข้อมูลโปรไฟล์เดิม
- ไม่เปลี่ยน API, handlers, state/effects, การบันทึก หรือสูตรคำนวณ กราฟพื้นที่เป็นส่วนแสดงผลเพิ่มเติมของจุดเดิม
- สารอาหารแสดงกรัมจริง รวมสถานะข้อมูลขาด/บางส่วน/ศูนย์ ไม่มีเป้าหมายกรัมจาก mockup; แท่งสีส้มสรุปสัปดาห์ยังหมายถึงพลังงานเผาผลาญ

## ผลตรวจ

- TypeScript client/server และ production build ผ่าน มีคำเตือนขนาด bundle เดิมและ annotation ของ dependency
- Playwright ผ่าน **18 กรณี**: scope 1, layout 2, reliability regressions 8, save flow 3, diary history 3, weight logs 1
- ตรวจทั้งสี่แท็บที่ **320, 390, 1440 px**: ไม่ล้นแนวนอน เมนูล่างสี่แท็บกดได้; ปุ่มบันทึกอาหาร/เป้าหมายไม่ถูกเมนูล่างบัง และหน้าวันนี้บนคอมยังเป็นสองคอลัมน์
- ตรวจซ้ำเฉพาะ scope test หลังเพิ่มข้อมูลน้ำหนักสองวันและการตรวจขนาดปุ่ม: ผ่าน ปุ่มกราฟและใช้มื้อซ้ำมีความสูงอย่างน้อย 44 px
- ตรวจภาพหลังแก้สีไขมันเหลือง โปรตีนแดง คาร์บส้ม และสถานะเลือกกราฟสีเขียว
- `git diff --check` ผ่าน ภาพอยู่ `.local/mockup-refresh-20261008/` โดยเลข 1–4 คือ วันนี้/บันทึก/ความคืบหน้า/บัญชี
