# เป้าหมายสารอาหารและ UI polish — 8 ต.ค. 2569

ทำใน branch `feature/Chayakorn05` ตามแผนที่อนุมัติ มี Luna Medium หนึ่งตัวแก้ UI ทั่วไป หัวหน้าทำสูตร เป้าหมายสารอาหาร ตรวจ diff และตรวจหลักฐาน ไม่ commit/push/deploy ในรอบนี้

## สิ่งที่แก้

- หน้าบัญชีและฟอร์มข้อมูลส่วนตัว: ปุ่มเปลี่ยนรูป/ลบรูปจัดกึ่งกลางระดับเดียวกัน พื้นที่แตะไม่น้อยกว่า 44px ไม่เพิ่มการ์ดน้ำหนัก/ส่วนสูง/BMI บนหน้าหลัก
- หน้าบันทึก: ช่องค้นหาพื้นขาว ตัวอักษรเข้ม placeholder ชัด กรอบเขียวเมื่อ focus และสี autofill สอดคล้องกับช่องค้นหา แก้กฎธีมที่ทับสีเดิม
- หน้ากล้อง: ปุ่มอัลบั้ม/ชัตเตอร์อยู่เหนือ bottom navigation บนจอสั้น ข้อผิดพลาดกล้องแสดงครั้งเดียว
- Today/สรุป 7 วัน/ค้นหา catalog: มีปุ่มลองโหลดหรือค้นหาอีกครั้ง ค้นหาคงคำเดิม สรุปรายสัปดาห์ไม่ค้างข้อมูลจากวันที่ก่อนเมื่อเปลี่ยนวันที่
- ประวัติ: ระหว่างกำลังโหลดไม่แสดงข้อความหลอกว่าไม่มีรายการ ทั้งหน้าหลัก ประวัติทั้งหมด และวันที่เลือก
- วันที่: มีวันที่รูปแบบไทยประกอบ date picker เดิม หัวข้ออาหารย้อนหลังตรงวันที่เลือก ชื่อช่องวันที่สำหรับ accessibility คงเดิม เวลามื้ออาหารมีข้อความรูปแบบ 24 ชั่วโมง
- ส่วนประกอบอาหาร: ชื่อและแคลอรีเต็มพื้นที่ ปริมาณอยู่ใกล้กัน ปุ่มลบ 44px แหล่งข้อมูลสั้นและเปิดดูรายละเอียดได้ การ์ดตัวอย่างที่ 390px สูงประมาณ 153px
- เป้าหมาย: พรีวิวคาร์บ/โปรตีน/ไขมันเป็นเปอร์เซ็นต์และกรัมจากพลังงานหลังบันทึก รองรับค่าประมาณและกำหนดเอง หน้าวันนี้ใช้เป้าหมายที่ยืนยันแล้ว พร้อมสถานะข้อมูลไม่ครบและการเทียบกรัมต่อวัน

ไม่เพิ่ม route, scanner, settings รวมศูนย์ หรือ API field ใหม่ สูตร TDEE และการคิดงบออกกำลังกายคงเดิม เป้าสารอาหาร derive จากข้อมูลเป้าหมายเดิม ไม่ต้องเพิ่ม schema หรือรัน migration/seed ดู [สูตร แหล่งอ้างอิง และข้อจำกัด](../goals.md)

## ผลตรวจ

- Unit สูตรเป้าหมาย: **12 ผ่าน** รวม AMDR/sum 100%, 4/4/9, ไม่ปัดระหว่างคำนวณ, ขอบเขตแคลอรีและ legacy default
- E2E เฉพาะส่วนที่เกี่ยวข้อง **33 เคสผ่าน** (นับเคสไม่ซ้ำ): macro targets 3, goals 5, reliability 8, UI polish 4, scope 1, save flow 3, profile photo 3, daily history 3, weight logs 1, layout 2
- ทดสอบมือถือกว้าง 320/360/390px และ desktop 1440px: ไม่ล้นแนวนอน ปุ่มรูปโปรไฟล์ตรงระดับทั้งหน้าหลักและฟอร์ม ช่องค้นหาชัดและกรอบ focus สีเขียว ปุ่มกล้องไม่ถูกเมนูล่างทับที่ 320×667, 360×800 และ 390×844
- บันทึกเป้าหมายล้มเหลวคง draft เปลี่ยนพรีวิวไม่เขียนข้อมูล บันทึกสำเร็จกลับหน้าหลักและอัปเดต Today/reload ใช้ข้อมูลเดิม API payload ไม่เพิ่ม field
- ข้อมูลสารอาหารว่าง/บางส่วน/ศูนย์/ครบและเกินเป้าหมายทดสอบแยกกัน แท่งเกินเป้าจำกัดเฉพาะความยาว แต่ตัวเลขและ accessibility แสดงจริง
- `npm run build` (typecheck client/server, Vite build, server build) **ผ่าน**; `git diff --check` **ผ่าน**
- Build ยังมี warning จาก annotation ของ Zod และ bundle หลักประมาณ 506kB ไม่ทำให้ build ล้มเหลว ไม่ได้ปรับ bundle ในงานนี้

พบปัญหาระหว่างตรวจและแก้แล้ว: สีพื้น/กรอบถูก premium theme ทับ, ชื่อ accessible date รวมคำอธิบายวันที่จนไม่ตรงชื่อเดิม, วันที่ไทยในปุ่มเลือกวันที่อยู่แถวเดียวจนชนกัน ชุดตรวจที่เกี่ยวข้องผ่านหลังแก้

## ภาพและข้อจำกัดหลักฐาน

ภาพอยู่ใน `.local/macro-ui-polish-20261008/` (ignored) เปิด `index.html` เพื่อดู Today, เป้าหมาย, บัญชี, บันทึก, กล้อง และฟอร์มตรวจอาหาร ภาพใช้ข้อมูลจำลอง ไม่มีข้อมูลลับ ภาพเต็มหน้าจะแสดงเมนู fixed ที่ตำแหน่ง viewport แรก; การตรวจว่าปุ่มบันทึกเข้าถึงได้ใช้ viewport หลังเลื่อนร่วมด้วย

E2E ใช้ API fixtures ไม่เขียน Supabase ของทีม ไม่เรียก AI จริง ไม่ทดสอบกล้อง/สิทธิ์แจ้งเตือนบนมือถือจริง และไม่ยืนยันว่า production บน Render อัปเดตแล้ว ยังต้อง build/push Docker image และ deploy ตามงานปล่อยรุ่นแยกต่างหาก
