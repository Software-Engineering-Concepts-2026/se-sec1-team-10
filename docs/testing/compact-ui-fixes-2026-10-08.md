# Compact UI fixes — 8 ต.ค. 2569

แก้บน branch `feature/Chayakorn05` ตาม system UI audit และคำขอลดความสูงการ์ด โดยคง API การคำนวณและ action เดิมไว้

## การเปลี่ยนแปลง

- Ingredient card ใช้ภาพตัวอย่าง 36px ชื่อยาวไม่เกินสองบรรทัด และวางปริมาณ ป้ายแหล่งข้อมูล รายละเอียดและปุ่มลบในแถวเดียวกันเมื่อมีพื้นที่พอ จอแคบเรียงแหล่งข้อมูลเหนือปุ่มรายละเอียด ช่องปริมาณกว้าง 72px สูง 44px ปุ่มลบ 44×44px รายละเอียดขยายภายในการ์ดโดยไม่ล้นจอ
- แก้ grid ของเวลาเตือนเป็นข้อความยืดหยุ่นกับช่องเวลาแยกต่างหาก ขยายช่องเวลาเป็น 44px และรักษาคำอธิบายภาษาไทยไว้ในพื้นที่ข้อความ
- ขยาย action ย่อยของประวัติอาหาร กิจกรรม น้ำหนัก และรูปโปรไฟล์ให้แตะได้ 44px; ปรับข้อความเมนูล่างเป็น 12px และขนาดตัวอักษรช่องกรอกเป็น 14px
- ปรับข้อความรองในสรุปอาหาร สารอาหาร ประวัติและบัญชีที่เล็กให้เป็น 12px คงหัวเรื่องเดิม เอาปุ่มออกจากระบบที่ซ้ำในหัวหน้าโปรไฟล์ออก โดยเมนูบัญชียังออกจากระบบได้ และถูก disable ระหว่างบันทึก
- ปรับ assertions เก่าให้ใช้ route, markup, ข้อความและหน่วยปัจจุบัน คงการตรวจค่าแคลอรี ปริมาณ request การสร้างมื้อใหม่ การแก้ไข id เดิม การแจ้งเตือน และ draft เมื่อผิดพลาดไว้
- เพิ่ม fixture ใน `e2e/compact-ui-fixes.spec.ts` สำหรับขนาด 320, 360, 390, 533 และ 1440px รวมข้าวจากฐานข้อมูล, ชื่อ AI ภาษาไทยแบบยาว, ปริมาณสามหลัก, หลายส่วนประกอบ, การแก้ปริมาณ, เปิด provenance, คำนวณใหม่, บันทึก และตรวจพื้นที่แตะ

## การตรวจสอบ

- `npm run build` ผ่าน รวม TypeScript typecheck และ Vite production build
- Browser regression: `npx playwright test --config .local/compact-regression.config.ts` บน Vite port 5312 และ Chrome ได้ 65 ผ่าน / 1 ล้มเหลวจาก locator ของ fixture ใหม่ที่จับ status สองข้อความ หลังปรับให้เจาะจง “ข้อมูลเปลี่ยนแล้ว” พร้อมตรวจว่าปุ่มบันทึก disabled รันเคสนี้ซ้ำผ่าน รวม 66 เคสได้รับการยืนยันผ่านจากชุดรวมและเคสที่แก้ ไม่มีเคสที่ยังล้มเหลว
- ตรวจที่ 320, 360, 390, 533 และ 1440px ไม่มี horizontal overflow การ์ดปิดรายละเอียดที่ 390/533px สูง **100px** ทั้งชื่อสั้นและชื่อ AI ยาว ที่ 320px สูง **122px** ช่องปริมาณสูง 44px ปุ่มลบกว้าง 44px เปิดรายละเอียดแล้วเนื้อหายังอยู่ภายในจอ
- แถวเตือนที่ 390px มีพื้นที่ข้อความ **211px** แทน 22px และช่องเวลาสูง 44px ยืนยันปุ่มแก้ไข/ลบทั้งหน้าบันทึกหลักและประวัติทั้งหมด รวมกิจกรรม น้ำหนักและรูปโปรไฟล์แตะได้อย่างน้อย 44×44px
- ตรวจภาพและ geometry ใน `.local/compact-ui-fixes-20261008/` ภาพใช้ข้อมูลจำลอง เช่นชื่อยาวและปริมาณ 350 กรัม ไม่ใช่ข้อมูลบัญชีจริง
- `git diff --check` ผ่าน ไม่มีการเรียก API จริงหรือฐานข้อมูล ไม่เพิ่ม feature หรือเปลี่ยนสูตรคำนวณ และยังไม่ได้ deploy ไป Render ผลรอบนี้ไม่ยืนยันกล้อง/notification บนอุปกรณ์จริงหรือ AI provider จริง
