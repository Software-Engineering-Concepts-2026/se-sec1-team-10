# ผลตรวจการแก้ UI และข้อมูลค้าง — 8 ต.ค. 2569

สาขา: `feature/Chayakorn05`

## สิ่งที่แก้

- โปรไฟล์รับน้ำหนักล่าสุดที่บันทึกจากหน้าความคืบหน้า แม้เปิดฟอร์มค้างไว้ โดยไม่ล้างชื่อและช่องอื่นที่กรอกไว้ น้ำหนักเก่าที่แก้ค้างอยู่จะถูกแทนด้วยค่าล่าสุด เมื่อไม่มีน้ำหนักเหลือ ช่องจะว่างแทนการนำค่าเก่ากลับมา การบันทึกไม่ผ่านเก็บ draft ไว้ ส่วนการปิดและเปิดฟอร์มใหม่ใช้ค่าที่บันทึกอยู่จริง
- กิจกรรมรับเฉพาะผลโหลดล่าสุดและทิ้งผลของวันก่อนหน้า เปลี่ยนวันแล้วล้างรายการ/สรุปเก่าและยกเลิกการแก้รายการเดิม ป้องกันเปลี่ยนวันหรือกดแก้/ลบซ้อนระหว่างบันทึก บันทึกไม่ผ่านเก็บ draft และโหลดไม่ผ่านหยุดแสดงสถานะกำลังโหลด
- แดชบอร์ดแสดง `—` เมื่อไม่มีข้อมูลสารอาหาร และระบุ `บางส่วน` เมื่อรวมได้เพียงบางรายการ ค่า 0 ที่ทราบจริงยังแสดงเป็น 0 หากข้อมูลหลักไม่ครบจะไม่แสดงสัดส่วนแท่งที่อาจทำให้เข้าใจผิด สีคาร์บส้ม โปรตีนแดง ไขมันเหลืองคงเดิม
- การทดสอบพบหน้าคอมยังมีข้อจำกัดความกว้างและคอลัมน์เดิม จึงคืนหน้า “วันนี้” เป็นสองคอลัมน์ตั้งแต่ 1024 พิกเซล หน้าบัญชี บันทึก และความคืบหน้ายังคงความกว้างแบบฟอร์มเดิม

ชุดใหม่ครอบคลุมน้ำหนักค้างถูกแทนด้วยน้ำหนักล่าสุด ชื่อที่กรอกยังอยู่ ลบน้ำหนักสุดท้ายเป็นค่าว่าง บันทึกโปรไฟล์ไม่ผ่าน/เปิดใหม่ การตอบกลับกิจกรรมเก่าหลังเปลี่ยนวัน การเปลี่ยนวันระหว่างแก้รายการ การส่งแก้ไขเฉพาะรายการของวันใหม่ โหลด/บันทึกกิจกรรมไม่ผ่าน และสารอาหารที่ขาดทั้งหมด/ขาดบางส่วน/ศูนย์จริง/ครบ/ไม่มีอาหาร

รันด้วย config ชั่วคราว `.local/reliability-check.config.ts` (Chrome, พอร์ต 5308, หนึ่ง worker) ชุดใหม่ผ่าน 7 กรณีก่อนเพิ่มกรณีโหลดกิจกรรมล้มเหลว จากนั้นกรณีใหม่และกรณีน้ำหนักค้างที่เพิ่มความเข้มของการตรวจผ่านทั้งสองกรณี ชุดเดิมผ่าน 6 กรณี และหลังคืน layout คอมผ่านอีก 3 กรณีที่เหลือ

ตรวจ TypeScript ฝั่ง client/server, Vite production build และ diff ผ่าน ภาพแดชบอร์ดที่ 320, 390 และ 1440 พิกเซลอยู่ใน `.local/ui-cleanup-check-20261007/` ตรวจภาพ 320 และ 1440 แล้วไม่มีเนื้อหาล้นหรือปุ่มถูกเมนูล่างบัง

## ขอบเขต

รอบนี้แก้ฝั่งหน้าเว็บและเพิ่มกรณีทดสอบ ไม่มีการเปลี่ยน schema, migration, seed หรือข้อมูล Supabase และยังไม่ได้ push หรือ deploy การตรวจเบราว์เซอร์ใช้ข้อมูลจำลอง จึงไม่ใช่หลักฐานตรวจ production เวอร์ชันใหม่

Vite ยังมีคำเตือนขนาด bundle หลักประมาณ 507 kB ก่อนบีบอัด เป็นข้อจำกัดเดิมและไม่ทำให้ build ล้มเหลว
