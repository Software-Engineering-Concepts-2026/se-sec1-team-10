# ปรับ UI และขั้นตอนบันทึก — 7 ตุลาคม 2569

Branch: `feature/Chayakorn05`

## พฤติกรรมที่เปลี่ยน

| ข้อ | ผลที่ได้ |
| --- | --- |
| 1. ฟอร์มยาวและซ้ำ | ฟอร์มอาหารที่เปิดจากหน้าบันทึกไม่มีรายการอาหารประจำวันซ้ำด้านล่าง บันทึกสำเร็จแล้วกลับหน้าบันทึกหลักพร้อมข้อความยืนยัน |
| 2. การ์ดอาหาร | ประวัติอาหารมีปุ่มแก้ไข/ลบแยกจากชื่อและปุ่มใช้มื้อเดิมซ้ำ การ์ดที่ไม่มีรูปยังใช้พื้นที่ชื่อได้เต็ม |
| 3. ลำดับตรวจอาหาร | รูปและชื่อ → มื้อและวันที่ → พลังงาน → สารอาหาร → ส่วนประกอบ → บันทึก ปุ่มท้ายฟอร์มอยู่ในลำดับเนื้อหาและมีพื้นที่เหนือเมนูล่าง |
| 4. ข้อความส่วนประกอบ | ใช้ป้ายแหล่งข้อมูลสั้น ๆ เช่น “ฐานข้อมูล” หรือ “ค่าประมาณ AI” พร้อมรายละเอียดที่กดเปิดได้ ฟอร์มว่างชวนเพิ่มส่วนประกอบเพื่อคำนวณพลังงาน |
| 5. เป้าหมาย | คง TDEE และตัวเลือกที่จำเป็น เน้นพลังงานปัจจุบันกับค่าหลังบันทึก ย้ายวิธีคำนวณไปเป็นรายละเอียดแบบพับได้ |
| 6. รูปแบบข้อมูล | ใช้วันที่แสดงผลภาษาไทยและปี พ.ศ. หน่วยส่วนประกอบเป็นกรัม พลังงานเป็น kcal และเพิ่มขนาดข้อความรองในส่วนที่แก้ ช่องเลือกวันที่แบบ native ยังคงรูปแบบของเบราว์เซอร์ |
| 7. Desktop | Today แสดงสรุปพลังงานกับรายการอาหารจริงที่โหลดไว้แล้วเป็นสองคอลัมน์บนจอใหญ่ และคงคอลัมน์เดียวบนมือถือ |

บันทึกกิจกรรมสำเร็จกลับหน้าบันทึกหลัก บันทึกข้อมูลส่วนตัวหรือเป้าหมายสำเร็จกลับหน้าบัญชี การบันทึกรูปโปรไฟล์อย่างเดียวไม่ปิดฟอร์มข้อมูลส่วนตัว เมื่อคำขอบันทึกไม่สำเร็จ ฟอร์มเก็บข้อมูลที่กรอกไว้ การแก้อาหารย้อนหลังรักษาวันของมื้อนั้นและไม่เปลี่ยนวันเริ่มต้นของมื้อใหม่โดยอัตโนมัติ
