## แก้ไขเพิ่มเติมก่อนเผยแพร่

พบ `ERR_ERL_UNEXPECTED_X_FORWARDED_FOR` ใน logs ของรุ่นก่อนหน้า จึงเพิ่มค่ากำหนด `TRUST_PROXY_HOPS` ให้ Express รับ IP ผ่าน proxy ตามจำนวน hop ที่ตั้งไว้ ค่าเริ่มต้นเมื่อไม่กำหนดยังคงไม่ trust proxy และปฏิเสธค่าที่ไม่ใช่จำนวนเต็มไม่ติดลบ

ตั้ง `TRUST_PROXY_HOPS=1` บนบริการ Render นี้ ไม่เปิด trust ทุก proxy และไม่ปิดการตรวจสอบ rate limit ตรวจ `APP_ORIGIN` ว่าตรงกับ HTTPS URL จริงแล้ว ไม่เปลี่ยนรหัสผ่าน/API key/registry credential/แผนบริการ

ไฟล์ที่เกี่ยวข้อง: `src/server/app.ts`, `src/server/index.ts`, `src/tests/auth-profile.test.ts`, `docs/deployment/render-docker.md`

หลักฐานทดสอบเพิ่มเติม:

- Typecheck ผ่าน
- Auth/profile suite ผ่าน 49/49 รวมการแยก rate limit ตาม client IP ด้านขวาสุด และการเปลี่ยน X-Forwarded-For ด้านซ้ายไม่ช่วยหลบ limit
- Rebuild image ผ่าน และ Docker smoke 13 กลุ่มผ่านด้วย `TRUST_PROXY_HOPS=1` ใช้ PostgreSQL ชั่วคราวและทำความสะอาดแล้ว
