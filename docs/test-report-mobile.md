## Fixes during verification

Hidden file inputs caused 9 px of overflow at 320 px; they now use display:none behind separate camera and album buttons. Removed the redundant third file input. Mobile presentation now applies at large widths as well. Dashboard/history requests guard against stale responses, and nutrition/summary views refresh after data changes. Favorite meals are scoped to the signed-in account on this device.
