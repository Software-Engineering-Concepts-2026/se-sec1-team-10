# Project Proposal

## สถานะเอกสาร

เอกสารนี้เก็บ snapshot ข้อเสนอและ MoSCoW priorities ในช่วงวางแผนเดิม ไม่ใช่บันทึกสถานะการพัฒนาปัจจุบันหรือการยืนยันว่าทุกข้อส่งมอบแล้ว ข้อเสนอเดิมให้ Issue #15 เป็น Must, Issue #29 และ #32 เป็น Should; User Stories ให้ US-07/Issue #15 เป็น Should และ US-12/Issue #29 กับ US-15/Issue #32 เป็น Must คงทั้งสองชุดไว้ตามต้นฉบับโดยไม่สรุปว่ามีการตกลงเปลี่ยน Priority แล้ว และข้อเสนอฉบับนี้ไม่ได้ระบุ Issue #30/US-13 เรื่อง Dashboard ย้อนหลัง 1 ปี ซึ่งมีอยู่ใน User Stories สำหรับข้อกำหนดอ้างอิงให้ดู [User Stories](requirements/user-stories.md); ความสามารถที่มีในระบบปัจจุบันให้ดู [คู่มือผู้ใช้](user-guide.md) และ [เอกสารสถาปัตยกรรม](architecture/README.md)

## Theme 
    Theme 3 : ข้อมูลแดชบอร์ดชีวิต 

## Project Name
    LifeBalance

## Persona หลัก
    - คุณปกรณณ์ (กรณ์) อายุ 32 ปี
    กรณ์เป็นคนรุ่นใหม่ที่ชีวิตขับเคลื่อนด้วยข้อมูล (Data-driven) เขามีตารางงานที่แน่นตลอดทั้งวัน ทั้งต้องประชุมกับทีม Engineer และวิเคราะห์ข้อมูลการตลาด เมื่องานเริ่มลงตัวเขาก็หันกลับมาใส่ใจสุขภาพอย่างจริงจังเพราะเริ่มรู้สึกอึดอัดจากพฤติกรรมการนั่งทำงานนาน ๆ (Sedentary Lifestyle) แต่ด้วยเวลาที่จำกัด เขาจึงต้องการจัดการทุกอย่างในชีวิตให้คุ้มค่าและรวดเร็วที่สุด

    - คุณมนัสวี (พิมพ์) อายุ 34 ปี
    พิมพ์เพิ่งคลอดลูกสาวคนแรกได้ไม่กี่เดือน ชีวิตของเธอกำลังเผชิญกับการเปลี่ยนแปลงครั้งใหญ่ ทั้งการปรับตัวกับบทบาทความเป็นแม่และการทำงานที่บ้าน (Work from Home) พิมพ์มีเวลานอนไม่เป็นเวลาและต้องคอยดูแลลูกตลอดทั้งวัน เธออยากลดน้ำหนักและฟื้นฟูรูปร่างให้กลับมาแข็งแรงเหมือนช่วงก่อนตั้งครรภ์ แต่การทำเช่นนั้นในขณะที่ยังต้องให้นมบุตรเป็นเรื่องที่ละเอียดอ่อนมาก เพราะเธอจะอดอาหารสุ่มสี่สุ่มห้าไม่ได้

## Value Proposition
    LifeBalance เป็นแดชบอร์ดที่ช่วยให้คนวัยทำงานซึ่งมีเวลาจำกัดสามารถดูแลสุขภาพได้ง่ายขึ้น โดยรวมข้อมูลเกี่ยวกับการกิน น้ำหนัก และสุขภาพไว้ในที่เดียว ทำให้ผู้ใช้ไม่ต้องเสียเวลาจดหรือค้นหาข้อมูลจากหลายที่ และสามารถดูภาพรวมของสุขภาพเพื่อนำไปปรับพฤติกรรมให้เหมาะกับการใช้ชีวิตของตัวเองได้

## MoSCoW priorities
   **Must Have**
    1. Issue #4 -- สมัครสมาชิก เพื่อบันทึกข้อมูลสุขภาพ 
    2. Issue #6 -- แก้ไขข้อมูลส่วนตัว เช่น อายุ น้ำหนัก ส่วนสูง
    3. Issue #8 -- คำนวณแคลลอรีจากอาหาร 
    4. Issue #9 -- คำนวณแคลอรีที่เผาผลาญจากการออกกำลังกาย 
    5. Issue #15 -- ดูสรุปแคลอรีที่ได้รับและใช้ไป 
    6. Issue #20 -- เข้าสู่ระบบด้วยอีเมลและรหัสผ่าน 

   **Should Have**
    1. Issue #16 -- กำหนดเป้าหมายน้ำหนัก
    2. Issue #17 -- ดูกราฟแนวโน้มน้ำหนักและ BMI
    3. Issue #19 -- ค้นหาประวัติการรับประทานอาหารย้อนหลัง 
    4. Issue #29 -- แสดงแถบความคืบหน้าแคลอรี
    5. Issue #32 -- แสดงค่า BMI ปัจจุบันบน Dashboard

   **Could Have**
    1. Issue #12 -- ระบบแจ้งเตือนมื้ออาหาร 
    2. Issue #14 -- บันทึกมื้ออาหารที่กินบ่อย 

   **Won't Have** 
    -ไม่มี-

## Risks & assumptions
   **Risks**
    - สมาชิกทีมอาจจะมีเวลาไม่ตรงกัน
    - ถ้าข้อมูลสุขภาพที่ผู้ใช้กรอกไม่ถูกต้อง อาจทำให้ผลการคำนวณและข้อมูล Dashboard ไม่ถูกต้อง

   **Assumption**
    - ผู้ใช้กลุ่มวัยทำงานมีความต้องการติดตามข้อมูลสุขภาพของตนเองในที่เดียว
    - ผู้ใช้ต้องการดูข้อมูลสุขภาพในรูปแบบ Dashboard ที่เข้าใจง่ายและใช้เวลาในการดูไม่นาน
